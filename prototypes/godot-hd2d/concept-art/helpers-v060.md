# Originale Helferanimationen v0.6.0

Erzeugt mit dem integrierten Imagegen-Werkzeug. Referenzen: Itoevas vorhandener
`fennec-combat.png` und `spirit-animation-v050.png` nur als Stilvorlage.
Alle finalen Assets liegen im Projekt; die Laufzeit referenziert keine temporären
Bildpfade. Die generierten PNGs bleiben unverändert, einschließlich Alpha.
Die JSON-Metadaten erfassen die tatsächlichen Alpha-Grenzen pro Zelle.

## Verbindliche gemeinsame Produktionsvorgaben

Use case: stylized-concept. Production 2D fantasy creature animation spritesheet
for Itoeva. Match softly painted pencil-and-watercolor woodland storybook fantasy,
delicate dark contours, warm natural fur/wood/feather textures and expressive faces.
Exactly 6 equal columns by 4 equal rows, landscape 1536×1024, true transparent alpha,
empty gaps, one whole creature per cell with comfortable margins and no overlap.
Same identity, equipment, scale and baseline throughout each row; three-quarter
facing right. Columns: ready, expressive idle, attack anticipation, committed
attack, recoil/block, recovery. Actual distinct limb/wing/ear/tail poses;
no sticker stretching, text, logos, borrowed game characters or opaque backdrop.

- `assets/combat/helpers-v060-4.png`: Pilzarchivar as russet hedgehog scholar with
  mushroom cap, birch-scroll satchel and open book; Distelheilerin as cream rabbit

  dusky blue flying squirrel with translucent leaf membranes and violet mist tail;
  Eichelhüter as chestnut seed golem with acorn helmet, oak scarf, root feet and buckler.

The distinctive motion suggestions were wing/gill movement, crouch/pounce, shell
lantern pulse, wing-assisted beetle ram, page/rune casting, twig staff jab, glide
pounce and shield bash. Six separately drawn frames per identity (96 in total).

Runtime: `data/helper_animations_v060.json`, `scripts/card_assets.gd`,
`scripts/card_view.gd`. Foot anchoring uses a fixed scale per form; no animated
size pumping. Import uses the existing Godot texture pipeline. PNG alpha and
all frame regions were inspected; actual arena screenshots are generated by
`tests/helpers_capture_v060.gd` and saved as Actions artifacts.
