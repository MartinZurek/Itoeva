# Integrationsstand 0.9.0

Vier Gegner, neun Reviere, zwei verbundene Landschaften und Vharok-Dreiphasenkampf sind integriert. Eigene zurückhaltende Kampfvisuals, zielgenaue Treffer und dezente Tonsignale werden aktuell geprüft. Noch kein APK-Bau und keine Gerätefreigabe. Dieser Zwischenstand verhindert erneuten Verlust lokaler Änderungen.
