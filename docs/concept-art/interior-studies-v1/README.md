# Innenraum-Konzeptstudien v1

Elf einzelne gemalte Gestaltungsvorlagen nach Martins Auftrag vom 10.10.2026.
Sie orientieren sich an den bisherigen Landschaftsstudien: feine warme
Bleistift-/Tuschekonturen, Farb- und Aquarellschichten auf cremefarbenem Papier,
gewachsene Holz-/Steinarchitektur, Pflanzen, Textilien und warmes Lampenlicht.

Jede Tafel hat eine grosse Raumansicht, eigene Moebelstudien und Tag-/Nachtvarianten.
Die Tafeln sind Referenzkunst. Sie werden nicht als flacher Hintergrund in den
Spielraum eingebaut. Martin wollte zuerst die Bilder sehen; die spaetere
Raumumsetzung soll begehbaren Boden, Moebeltiefe, Verdeckung und zum Avatar
passende Pixelgruppen aus diesen Vorlagen ableiten. Noch keine neue Raumgeometrie
aus diesen Tafeln implementiert.
