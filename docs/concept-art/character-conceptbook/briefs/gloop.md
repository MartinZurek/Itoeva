# Gloop

Bestehendes Wesen / Fantasy-Variante

Status: Designentwurf; Ablage als GitHub-Referenz freigegeben. Neue Figuren bleiben Vorschlaege.

Bild: ../images/gloop-character-fantasy-study-v1.png

## Wiedererkennung
Niedrige runde Moosgrün-Silhouette, sanfte dunkle Augen, weiche Körpermasse.

## Fantasy-Akzent
Kleine Blattschulter, winziger Samenstein im durchscheinenden Körper und seitliche Tasche.

## Bewegung
Langsames Stauchen und Strecken mit stabilem Bodenkontakt; kurze Pausen vor Richtungswechseln.

## Pixel-Art
Keine glasartigen Vollflächenreflexe. Außenkontur, Gesicht und eine helle Innenkante genügen für Transparenz.

## Startpalette
#35493B / #5D754B / #8FA565 / #BCC58B / #DDE0AF / #9A7957 / #B8D6BB / #F0EBC8

Exakter Farb-Vorschlag, keine technisch gemessene Bildpalette.

## Relative Groesse
38 bei Reisender = 100; Vorschlag, keine Pixelzahl. Die Tafel ist nicht massgleich. Bestehende Spielgroessen vorerst beibehalten.
