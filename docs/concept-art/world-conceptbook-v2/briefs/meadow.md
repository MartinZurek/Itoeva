# Blumenwiese (MEADOW)

Status: Entwurf; als Referenz in PR #326 hinterlegt.

Bild: ../images/meadow-pixel-concept-v1.jpg

## Bildfokus
Eine ruhige freie Lichtung trennt die Spielfigur von den Blumeninseln.

## Tiefe
Weiche Baumlinie; lockere Büsche; klare Grasfläche; Blumen nur in Gruppen an den Rändern.

## Startpalette
#3B5948 / #65844F / #A2B56B / #DDD39A / #F0C56B / #C58693 / #96BDB8 / #F7E9C8

Exakter Palettenvorschlag, nicht die technisch gemessene Palette der generierten Tafel.

## Requisiten
Blumenbüschel, Sitzstamm, niedriger Busch, kleiner Stein

## Animation
Blumen bewegen sich in gemeinsamen Windgruppen; Schmetterlinge bleiben sparsame Akzente.

## Abgleich mit dem Spiel
Im Code steht eine Bank. Der Sitzstamm der Studie ist eine Alternative; für den ersten Schritt Bank und Stationsanker erhalten.
